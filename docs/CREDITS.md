# Crédits et Licences — AWS : Africa World Saving

Ce document répertorie l'ensemble des technologies open source, bibliothèques logicielles, polices typographiques et ressources graphiques utilisées pour bâtir la plateforme **AWS : Africa World Saving**.

---

## 1. Cadre Applicatif & Moteur Web
- **Next.js 15 (App Router & Turbopack)** — Développé par Vercel sous licence MIT.
- **React 19 & React DOM** — Développé par Meta sous licence MIT.
- **TypeScript 5.7** — Développé par Microsoft sous licence Apache 2.0.
- **Tailwind CSS 3.4** — Développé par Tailwind Labs sous licence MIT.

---

## 2. 3D & Graphismes Interactifs
- **Three.js** — Moteur WebGL développé par Ricardo Cabello (Mr.doob) et ses contributeurs sous licence MIT.
- **@react-three/fiber & @react-three/drei** — Écosystème R3F maintenu par Poimandres sous licence MIT.

---

## 3. Données, Base de Données & Authentification
- **Neon Serverless PostgreSQL** — Plateforme Postgres managée avec branching et isolation.
- **Drizzle ORM & Drizzle Kit** — ORM TypeScript haute performance sous licence Apache 2.0.
- **Better Auth** — Solution moderne d'authentification et de gestion de session sous licence MIT.
- **Zod** — Schémas et validation TypeScript par Colin McDonnell sous licence MIT.

---

## 4. Télécommunications & Paiement
- **LiveKit Server SDK** — Plateforme open source audio/vidéo WebRTC temps réel sous licence Apache 2.0.
- **Chariow API & Pulse Webhooks** — Passerelle panafricaine de paiement par Mobile Money et Cartes Bancaires.
